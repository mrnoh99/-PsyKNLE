간호사 국가시험 정신간호학 기출문제 풀이

홈 고객지원 개인정보처리방침 이용약관

앱 소개

PsyKNLE은 간호사 국가시험 2교시 정신간호학(71~105번) 기출문제를 연도별로 풀고 해설을 확인할 수 있는 iOS 학습 앱입니다. 2020년(제60회)부터 2026년(제66회)까지 245문항을 담고 있습니다.

  • 문제풀기와 답안보기 두 가지 학습 모드
  • 문항마다 정답 근거와 오답 보기를 설명하는 해설
  • 간호과정 단계(사정·진단·계획·중재·평가)별 분류
  • 연도, 풀이 상태, 분류, 별표, 메모 필터와 키워드 검색
  • 회원가입 없이 사용하며, 학습 기록은 기기 안에만 저장
고객지원 사용 방법, 자주 묻는 질문, 문의하기 개인정보처리방침 앱이 처리하는 정보와 이용자의 권리 이용약관 서비스 이용에 관한 기본 안내
