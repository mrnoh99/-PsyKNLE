사용 방법

앱 내 우측 상단 ⓘ 버튼에서 전체 사용설명을 볼 수 있습니다. 아래는 주요 기능 요약입니다.

학습 모드

  • 문제풀기: 문항을 선택해 답을 고르고 [제출]합니다.
  • 답안보기: 정답, 해설, 키워드, 메모를 확인합니다.
  • 목록에서 문항을 터치하면 한 문항씩, [▶] 버튼으로는 필터된 문항을 연속으로 볼 수 있습니다.

필터 · 검색

  • 연도(2026~), 풀이 상태(정답/오답/풀지 않음), 분류(사정/진단/계획/중재/평가)를 조합할 수 있습니다.
  • 별표·메모 필터로 중요 문항이나 메모가 있는 문항만 볼 수 있습니다.
  • 키워드 검색은 부분 일치와 동의어(예: PTSD, SSRI)를 지원합니다.

해설 · 메모 · 키워드

  • 답안 화면에서 해설, 별표, 개인 메모, 사용자 추가 키워드를 관리할 수 있습니다.
  • 중복 정답 문항은 답가지를 여러 개 선택할 수 있습니다.

데이터

  • 학습 기록은 기기 내부에 저장되며 서버로 자동 전송되지 않습니다.
  • 앱 업데이트 시 문항·해설은 갱신되고, 학습 기록과 추가 키워드는 유지됩니다.

자주 묻는 질문

학습 기록이 사라졌어요.

학습 기록은 기기 내부에 저장됩니다. 앱 삭제, 기기 변경, iCloud 백업 복원 방식에 따라 데이터가 초기화될 수 있습니다. 앱 업데이트만으로는 일반적으로 기록이 유지됩니다.

문항 수가 예상과 달라요.

앱 실행 시 최신 시드 데이터와 동기화됩니다. 이전 버전에서 남은 문항이 정리될 수 있으며, 앱을 완전히 삭제 후 재설치하면 초기 상태로 돌아갑니다.

키워드 검색이 안 맞는 것 같아요.

키워드 검색은 부분 일치와 동의어(예: PTSD, 사회공포증)를 지원합니다. 문항별 사용자 추가 키워드도 검색에 반영됩니다.

모든 데이터를 초기화하려면?

iPhone/iPad에서 앱을 삭제한 뒤 App Store에서 다시 설치하면 학습 기록과 사용자 입력이 초기화됩니다.
